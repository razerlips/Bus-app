# バス予定（鬼無里線）

長野市営バス 鬼無里線（平日のみ）の便を、iPhoneのカレンダーにタップで追加するWebページです。

## 使い方
1. ページを開いて「＋ 区間を登録」で乗るバス停・降りるバス停を選ぶ（帰りの区間も一緒に登録できます）
2. 「今日 / 明日 / 日付」を選ぶ
3. 乗る便の「カレンダーに追加」をタップ → iPhoneのカレンダー画面で「追加」

区間と通知の設定は、そのiPhoneのブラウザに保存されます。Safariの共有ボタンから「ホーム画面に追加」すると、アプリのように使えます。

## ファイル
- `index.html` … ページ本体
- `data/kinasa.json` … 時刻表データ（2026年4月1日制定・素案）。`down` が鬼無里方面、`up` が長野方面で、各停留所に6便分の時刻が入っています

時刻表が変わったら `data/kinasa.json` を差し替えてください。
